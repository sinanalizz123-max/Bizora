# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Unreleased

### Added
- Project scaffold (Compose, Material 3, Room, DataStore, Navigation).
- First-time onboarding flow with business type and starter product templates.
- Product management with categories, variants, tax, and weight-based products.
- Selling/POS with product grid, search, cart, discounts, tax, and cash payments.
- Optional modules: Inventory, Customers, Expenses (toggleable in settings).
- Sales history list with transaction numbers (INV-xxxxxx).
- GitHub Actions CI: debug build + unit tests, signed release on tags.
